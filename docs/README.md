## Internal Direction

The main direction is to keep the app understandable for normal users while preserving admin power:

```text
Describe -> Evidence -> Review -> Save
```

Advanced source, media, AI, packaging, and publishing controls should sit behind expert/admin paths rather than becoming the first screen for contributors.
