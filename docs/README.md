# topic.earth participation documents

These four working documents describe a proposed path from climate education to local citizen initiatives. They are planning materials, not a statement that the login system or municipal partnerships have already been implemented.

## Shared proposal

- Keep the Fever Loop and other educational content open to visitors without requiring an account.
- Propose **16 years** as the minimum age for active participation, with specific safeguards for 16- and 17-year-olds. This is a proposed product policy, not a claim that educational reading requires this age by law.
- Organize initiatives by **commune → region → country → world**. A visitor can browse other places; verified locality is relevant only to local privileges.
- Offer a separately approved **local Ambassador** role. Identity verification does not grant authority to speak for a commune. An official municipal representative requires independent authorization.
- Use Discord only as an optional, moderated discussion space and GitHub as an optional contributor login. Neither alone proves age or residence to topic.earth.

## Before implementation

Confirm itsme's available attributes, integration terms and costs; define age-specific posting and moderation rules; agree how local connection is verified; and establish how a participating commune authorizes its representatives. The documents keep these items open rather than assuming an agreement or technical capability.

The three civic notes convey the same proposal in Belgium's French, Dutch, and German languages. The English brief is intended for implementation planning.
