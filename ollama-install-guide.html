Local Ollama · Quick setup

Run a model on your own computer and connect it to topic.earth API Settings. Start with one small model; you can choose any installed model later.

1. Install or update Ollama

Use the official Ollama download for Windows, macOS or Linux. On Windows, open the Ollama app after installing. If Ollama is already running, you do not need a second ollama serve process.

2. Download a model

Qwen 3.5 · 4B

About 3.4 GB download

A current compact multilingual model for local text testing on a 16 GB computer. Actual memory use depends on context and hardware.

ollama pull qwen3.5:4b
Model details

Gemma 3 · 4B

A compact alternative with text and image support. topic.earth's Ollama text setting uses it for text prompts.

ollama pull gemma3:4b
Model details

Already have llama3.1:8b or another model? Keep using it if you prefer. No download is required just to change this guide.

3. Connect API Settings

  1. Open topic.earth API Settings and choose Ollama for text.
  2. Keep the host at http://localhost:11434 when Ollama runs on the same computer.
  3. Refresh installed models, select qwen3.5:4b (or your own model), save, then use the Ollama test.

The model must be installed on the device running the browser. A visitor to topic.earth does not use your computer's Ollama server.

Check this browser

This reads localhost:11434/api/version and /api/tags. It does not generate a prompt.

    If the connection fails

    • Check that the Ollama app is running and that ollama list shows your downloaded model.
    • A page on https://www.topic.earth may need its exact origin allowed in Ollama using OLLAMA_ORIGINS; restart Ollama after changing it. Browser local-network restrictions can also apply. See the official origin guidance.
    • Do not bind Ollama to the public internet or allow every origin to fix a browser error. The local API has no authentication by default.

    Local Ollama requests stay on your machine only when the selected host is local and external fallbacks are disabled. Other topic.earth features may still use online services. Ollama API authentication details.
